# Java Notes App

A simple text-based Notes Manager developed using Java File I/O.

## Features

- Add notes
- Save notes to a text file
- Read saved notes
- View previously stored notes
- Simple console-based interface

## Technologies Used

- Java
- FileWriter
- FileReader
- Scanner
- VS Code
- Terminal

## How to Run

Compile the program:

javac NotesApp.java

Run the program:

java NotesApp

## Learning Outcome

This project demonstrates how Java can write data to a file and read persistent data from a file using FileWriter and FileReader.
